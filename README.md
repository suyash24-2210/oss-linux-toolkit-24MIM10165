\## Project Overview



This project demonstrates basic Linux automation using Bash scripts.



\## Scripts Included



sys\_health\_monitor.sh – Displays CPU, memory and disk usage.



foss\_package\_report.sh – Lists installed open source packages.



directory\_security\_scan.sh – Checks directory permissions.



log\_keyword\_tracker.sh – Searches log files for keywords.



open\_source\_story.sh – Generates a small open source story.



\## Running the scripts



Make scripts executable:



chmod +x \*.sh



Run example:



./sys\_health\_monitor.sh
